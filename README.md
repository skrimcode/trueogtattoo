# True OG Tattoo — лендинг тату-студии

Одностраничный сайт для тату-студии True OG Tattoo в Путилково.

## Стек
- Чистый HTML / CSS / JS без фреймворков и сборки
- Адаптивная вёрстка (mobile-first, breakpoints 380/560/820/1100/1600/2000)
- Schema.org разметка (LocalBusiness, FAQPage, BreadcrumbList, WebSite)
- Open Graph + Twitter Card
- SEO: sitemap.xml, robots.txt, canonical, geo-метки
- Accessibility: skip-link, aria-атрибуты, focus-trap в мобильном меню, prefers-reduced-motion
- Производительность: lazy-loading, preload hero-постера, contain: layout paint


## Локальный запуск

Просто открой `index.html` в браузере или подними локальный сервер
